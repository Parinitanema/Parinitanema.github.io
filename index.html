Teaching models

I work on continual and incremental learning for computer vision — models that keep absorbing new classes from a live data stream while holding on to everything they already know.

My recent work removes two crutches these systems usually lean on: a stored buffer of old examples, and someone telling the model when one task ends and the next begins.

Research

Three threads

All of them come back to the same question: what has to stay fixed, and what is allowed to move, when a model meets a class it has never seen?

Learning a new class from five examples

In few-shot class-incremental learning, each new class shows up with a handful of samples. Almost everything then depends on how good the base representation was before those classes arrived — so that is where I put the work, shaping the base feature space through feature augmentation so it still has room for classes it was never trained on.

WACV 2025 · few-shot CIL · feature augmentation

Streams with no task boundaries

Real data does not arrive in tidy labelled tasks. It arrives once, in a single pass, with classes quietly mixing and shifting. GOFOR handles this with no gradient updates at all: an orthogonal random projection, prototypes pulled apart using the running covariance, and a drift detector that decides when the model is allowed to change.

BMVC 2026 · online task-free CIL · exemplar-free

More than one modality

Vision is not the only stream that keeps growing. I work on class-incremental learning where audio and video have to be reconciled, and on speech recognition that adapts across Indian languages instead of being retrained from scratch for each one.

ESWA 2026 · Interspeech 2024 · audio–visual · multilingual speech

Publications

Papers

Newest first.

  1. 2026

    Gradient-Free Orthogonal Feature Organization for Online Task-Free Class-Incremental Learning

    Parinita Nema, Vinod K Kurmi

    British Machine Vision Conference (BMVC) Accepted

    Organises the feature space through closed-form updates instead of backpropagation, keeps no exemplars, and refreshes only when a Sliced-Wasserstein drift detector says the stream has actually moved. Improves on prior work by up to 14.5% across CIFAR-10, CIFAR-100, CORe50 and CUB-200.

  2. 2026

    PromptCIL: Feature-Guided Prompting for Audio-Visual Class-Incremental Learning

    Rini Smita Thakur, Aditya Kumar Singh, Parinita Nema, Vinod Kumar Kurmi

    Expert Systems with Applications In press

    Feature-guided prompting for class-incremental learning when the arriving classes are audio-visual rather than image-only.

  3. 2025

    Strategic Base Representation Learning via Feature Augmentations for Few-Shot Class Incremental Learning

    Parinita Nema, Vinod K Kurmi

    IEEE/CVF Winter Conference on Applications of Computer Vision (WACV), pp. 6394–6403

    Builds a base representation that leaves usable room for classes it has not met yet, so the few-shot sessions that follow are not fighting the backbone.

  4. 2024

    Towards Robust Few-Shot Class Incremental Learning in Audio Classification Using Contrastive Representation

    Riyansha Singh, Parinita Nema, Vinod K Kurmi

    Interspeech 2024, pp. 5023–5027

    Carries the few-shot incremental setting over to audio, using contrastive representations to keep earlier sound classes separable.
